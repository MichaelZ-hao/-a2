# Unity Delivery Route Project

## Unity version

Unity `6000.3.19f1`

## Open the project

1. Clone or download this repository.
2. Open the project folder in Unity Hub.
3. Open `Assets/_Project/Scenes/B_CityRoute.unity`.

The `Library`, `Temp`, `Obj`, `Build`, `Logs`, and `UserSettings` folders are intentionally excluded from version control. Unity regenerates them after the project is opened.
